# isaac · personal portfolio

Personal portfolio and blog built with [Hugo](https://gohugo.io/) and the [Blowfish](https://blowfish.page/) theme. Covers my homelab infrastructure, self-hosted projects, and technical write-ups.

## What's in here

- **About** — who I am, my stack, and my hardware
- **Projects** — write-ups of homelab builds and self-hosting setups
- **Blog** — practical notes and things I've figured out the hard way

## How it's hosted

The site runs entirely on self-hosted infrastructure, no cloud involved.

### Hugo

The site is a static site generated by Hugo with the Blowfish theme. Content lives in `content/` as Markdown files and the output is a folder of plain HTML, CSS, and JS — no runtime dependencies.

### Debian LXC on Proxmox

Hugo runs inside a lightweight **Debian LXC container** on my Proxmox homelab server. The container serves the built static files via Nginx and rebuilds automatically on content changes.

### Nginx Proxy Manager

**Nginx Proxy Manager (NPM)** handles reverse proxying inside the homelab — routing incoming traffic to the Hugo container, managing SSL termination, and acting as the internal entry point for the site.

### Cloudflare Tunnel

Public traffic reaches the homelab through a **Cloudflare Tunnel** (`cloudflared`), which creates an outbound-only encrypted connection from the LXC to Cloudflare's edge. No ports are exposed on the router. Cloudflare handles DDoS protection, caching, and the public DNS entry.

```
Visitor → Cloudflare Edge → Cloudflare Tunnel → NPM → Hugo (Debian LXC)
```
